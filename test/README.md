三个镜像，按顺序用。全程只动 `boot_b`，`/data` 一个字节都不写；回安卓随时可以。

| 文件 | sha256（前 8 位） | 用途 |
| --- | --- | --- |
| `boot-t50-timed.img` | `27074a84` | **现在测这个**：不画色条、进内核 8 秒后自我重启，用来判断内核入口死没死 |
| `boot-t50-probe.img` | `3d811f83` | 第一次测过的显示驱动版（绿条后黑屏重启） |

## 现在这一步：计时版

它和上一版唯一的区别：

- 把「入口处画蓝条 / MMU 前画品红条」的代码换成了空操作 → 看不到色条是**预期**的
- 关掉了 panic 屏文字
- 打开「MMU 打开后再等 8 秒，然后 PSCI 自我重启」

所以这次**唯一的信号是重启的时间点**。

### 步骤

1. 手机关机 → 音量下 + 电源 → 进 fastboot → 插线
2. 双击 `1c-flash-t50-timed.cmd`
   （或者不写盘：`fastboot boot boot-t50-timed.img`，只跑一次）
3. 手机自动重启进 b 槽
4. 盯着屏幕，**从绿条消失、变成黑屏那一刻开始计时**，到它自己重启为止

### 结果怎么读

- **约 8 秒才重启** → 内核入口、MMU 都活着，问题在后面（根卷 / 驱动 / 用户态）
- **1~2 秒就重启** → 内核入口就崩了，跟根卷无关
- **一直黑屏不重启** → 8 秒的 reset 也没跑到，同样说明入口处就挂了

把这三种里的哪一种告诉我就行，不用拍照。

## 刷完怎么回安卓

双击 `2-back-to-android.cmd`，或者手机进 fastboot 后跑：

```
fastboot --set-active=a
fastboot reboot
```

## 如果刷写被拒绝

脚本会在写盘前检查产品名、解锁状态、`boot_b` 容量和镜像 sha256，任一项不对就退出、不写盘。
`boot-t50-timed.img` 是 12,382,208 字节，`boot_b` 有 201,326,592 字节，装得下。
